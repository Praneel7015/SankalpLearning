# Sankalp Learning Ghost Theme

A simple custom Ghost theme for Sankalp Learning Solutions.

## What this includes

- Custom homepage and static pages
- Post, author, and tag templates
- Reusable partials and SVG icons
- Theme styles and JavaScript in `assets/`

## Project structure

- `assets/` - CSS, JavaScript, and images
- `partials/` - Shared Handlebars partials
- `*.hbs` - Theme template files
- `package.json` - Theme metadata and config

## How to use

1. Copy this theme into your Ghost `content/themes/` folder.
2. Restart Ghost (if needed).
3. Go to Ghost Admin -> Design and activate this theme.

## Development

Edit `.hbs`, CSS, and JS files directly in this project.
